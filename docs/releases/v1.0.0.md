# punchlist 1.0.0 — first stable release

2026-08-31 · stable · npm dist-tag: `latest`

## Highlights
The first public release of punchlist: a **self-hosted, agent-first task
manager** you and your AI agents share. One local server (default
`127.0.0.1:8600`), a web app, a CLI, and an MCP server over the same task
list — with a security model built for letting agents act on it.

- **Shared human/agent queue** — every task has a `created_by` and an
  `assignee`; agent work flows active → claim → in_progress → finish →
  review → you approve → done.
- **Delegate to AI agents** over MCP, and keep control: a review lane, an
  approval gate, and per-actor tokens.
- **Templates & workflows** (`plt`) — task templates with an output shape +
  golden exemplar, and multi-step workflows that spawn tasks in order.
- **Email becomes tasks**, quarantined until you vet them.

## Install
```bash
npm install -g @aronvaughan/punchlist   # latest
punchlist --version                      # 1.0.0
# then open http://127.0.0.1:8600
```

## Changes

### Added
- Task server: Node + Hono + SQLite (WAL), a web app, a CLI, and an MCP server.
- Human/agent delegation with `created_by` / `assignee`, claim/finish/review,
  and an owner approval gate.
- Per-actor bearer tokens; an agent security model that screens task text as
  untrusted data and quarantines unvetted (e.g. email-sourced) tasks.
- Templates + workflows via `plt`; an in-app template editor.
- Projects, tags, backlog ordering, due/when scheduling, and saved views
  (today, inbox, upcoming, overdue, review, delegated, logbook).
- Image attachments; a SilverBullet-backed instance KB.
- A theme system that follows the OS (light/dark) with a picker.

### Security
- Strict CSP; untrusted-task screening; a private `data/` plane kept out of
  tracked paths so open-sourcing the repo can't leak instance data.
