# punchlist 1.0.1-rc.1 — safer pushes & agent KB context

2026-09-02 · release candidate · npm dist-tag: `next`

## Highlights
- **Agents get project context.** Projects, tags, and the instance now carry a `kb_path` — a KB folder an agent reads before working that project or tag — with CLI to create and set it.
- **Restart without interrupting work.** A task can queue a *deferred* restart that applies only once no task is in progress.
- **A pre-push safety gate.** A leak scan (secrets + PII, across full git history) and a shareable diff-review page now gate every push of the repo.
- **Safer directory browsing** and a handful of UI/UX fixes.
- Patch-level and backward compatible — safe to adopt from 1.0.0.

## Upgrade
```bash
npm install -g @aronvaughan/punchlist@next   # candidates ship under `next`, not `latest`
punchlist --version                          # expect 1.0.1-rc.1
```
When promoted to stable, `1.0.1` becomes `latest`:
`npm dist-tag add @aronvaughan/punchlist@1.0.1 latest`.

## Breaking changes
None. This is a patch release — existing tasks, tokens, and the DB schema are unchanged.

## Changes

### Added
- `kb_path` on projects and tags — a KB folder for agent context/notes (f07e6d6).
- Instance-level `working_dir` / `kb_path`, mirroring the project and tag pickers (14ab925).
- `pl.sh project-create`, plus `project-edit` / `tag-edit` that set `kb_path` on existing rows (dd25e4d, 855578a).
- Deferred safe-restart — `request-restart` / `safe-restart` / `restart-status`: a queued restart that applies only when no task is `in_progress` (7152caf).
- Pre-push process — `repo-leak-scan` + `pre-push-review` templates and a `pre-push` workflow (scan → review → push), with a maintainer doc (61106d9).

### Changed
- The working-directory browser now shows hidden directories but denylists known-sensitive names, and allows `.claude` directories as targets (5682cf1, c2615bb).
- Agents are instructed to keep task comment/finish text brief and bulleted (384a328).

### Fixed
- The timeline sparkline draws a dashed axis + today-ring when today has no activity, instead of showing a gap (aeb43d7).
- A failed `/templates` fetch no longer permanently blanks the task template picker — it retries the next time the picker opens (`public/detail.js`, ships with 1.0.1).
