v1.1.0: the process spine

Templates and workflows gain a process spine: `plt` launches a run from a
workflow formula, pins every step to the tree it was done on, records receipts
for skills, agents, artifacts and GitHub facts, holds human gates as yes/no
signals, and renders a run page and an effort index. Ships the build-and-ship,
review-pr, spike and discard cycles, the editable page templates they use, and
a private-first publish flow (scripts/publish.sh).
